Design lessons recorded:
  - Cross-field agent extension: keep the architecture, replace the
    vocabulary. Don't force one field's claim types onto another's
    papers. The chem paper's LOD is not a physics claim, the math
    paper's Lemma is not a physics equation.
  - When extending prompts, keep examples abstract. Concrete examples
    from one specific paper (Ti3AlC2 etching, essentially purely
    pseudo-Anosov, K/ε = 20) drift the model toward that paper's
    subdomain even for unrelated inputs. Use domain-general vocabulary
    (reagents X + Y at temperature T; theorem / lemma / definition;
    hypothesis / model equation / measurement).
  - Long heredoc patches with nested triple-quoted strings are
    fragile. When patch >100 lines with complex escapes → write the
    function bodies as a separate .py file and patch the caller with
    just an import + one-line invocation.

Adım 5 — Reproducibility field-conditional
------------------------------------------
Field-specific keyword lists added:
  BIO_AVAILABILITY_KEYWORDS: GEO/SRA/ENA/PDB accession, IRB, IACUC,
    ethics approval, sample size, replicates, protocols.io deposits.
  BIO_METHODOLOGY_KEYWORDS: cell line, iPSC, CRISPR, antibody clone,
    PCR / qPCR / RNA-seq / ChIP-seq / ATAC-seq, Western blot,
    flow cytometry, patch clamp, optogenetics, phylogenetics,
    differential expression.
  CHEM_AVAILABILITY_KEYWORDS: Supporting Information, characterization
    data, CCDC deposition, CIF files.
  CHEM_METHODOLOGY_KEYWORDS: HPLC / LC-MS / GC-MS / NMR / IR / Raman /
    UV-Vis / XRD / XPS / EXAFS / TEM / SEM / HAADF-STEM / EDS / TGA /
    DSC / BET, cyclic voltammetry, EIS, DFT, MD, synthesis /
    purification / workup / yield / calibration curve.

_scan_signals(parsed, field="physics") uses AVAILABILITY_KEYWORDS +
ALGORITHM_KEYWORDS as base and adds bio/chem lists on top when the
field matches.

_decide_gate(paper_types, signals, field="physics") does field-first
routing:
  field=math          -> scrutiny=none  (formal proofs; not applicable)
  field=biology       -> scrutiny=deep  (experimental / computational)
  field=chemistry     -> scrutiny=deep  (experimental / computational)
  field=physics       -> original theoretical/computational logic

analyze_reproducibility derives field_top from the classification
cache and threads it through both _scan_signals and _decide_gate.

Adım 4 — Structure trigger field-conditional
--------------------------------------------
Field-specific regex trigger patterns added alongside the existing
physics-agnostic list (which mostly contains cross-field hedges like
"trivially follows", "it is easy to see", "we omit"):

  BIO_TRIGGER_PATTERNS: "we hypothesi[sz]e", "results (indicate|
    suggest|show)", "consistent with", "in (good|excellent) agreement",
    "may (play a role|contribute)", "correlated with", "we observed",
    "appears to", "cannot (rule out|exclude)", "further studies
    needed".
  CHEM_TRIGGER_PATTERNS: "confirmed by", "as expected", "successfully
    synthesi[sz]ed / demonstrated", "indicates the presence of",
    "attributed to", "the enhanced (performance|activity|selectivity|
    stability)", "structure was confirmed", "can be (attributed|
    assigned) to".
  MATH_TRIGGER_PATTERNS: "one easily sees / verifies", "an argument
    shows", "similar to the proof of", "without loss of generality",
    "WLOG", "it suffices to", "by a standard argument", "mutatis
    mutandis", "analogous(ly)?".

scan_sections(parsed, field="physics") merges the base compiled list
with the field-specific compiled list.

analyze_structure derives field_top from the classification cache
and passes it to scan_sections. A local _classification_for helper
was added (mirrors reproducibility_agent's approach).
