Design lessons recorded:
  - Cross-field agent extension: keep the architecture, replace the
    vocabulary. Don't force one field's claim types onto another's
    papers. The chem paper's LOD is not a physics claim, the math
    paper's Lemma is not a physics equation.
  - When extending prompts, keep examples abstract. Concrete examples
    from one specific paper (Ti3AlC2 etching, essentially purely
    pseudo-Anosov, K/ε = 20) drift the model toward that paper's
    subdomain even for unrelated inputs. Use domain-general vocabulary
    (reagents X + Y at temperature T; theorem / lemma / definition;
    hypothesis / model equation / measurement).
  - Long heredoc patches with nested triple-quoted strings are
    fragile. When patch >100 lines with complex escapes → write the
    function bodies as a separate .py file and patch the caller with
    just an import + one-line invocation.
